# Google Search AI Agent

An AI-powered Google Search Agent built using Python, LangChain, Groq LLM, and Google Serper API.

## Features

- Accepts user queries through the terminal.
- Uses Groq LLM for AI-powered responses.
- Searches Google using Google Serper API.
- Automatically decides when to use the Google Search tool.
- Generates answers based on search results.
- Supports continuous user interaction.

## Technologies Used

- Python
- LangChain
- Groq LLM
- Google Serper API

## Installation

1. Clone the repository:

git clone https://github.com/zeeshan-ansari-01/google-search-ai-agent.git

2. Navigate to the project folder:

cd google-search-ai-agent

3. Install dependencies:

pip install -r requirements.txt

4. Create a `.env` file and add your API keys:

GROQ_API_KEY=your_groq_api_key
SERPER_API_KEY=your_serper_api_key

5. Run the project:

python main.py

## Usage

Enter your question in the terminal. Type `quit` to exit the application.
